## 1. 产品、技术与交付边界

这是中文界面、第三人称、明亮卡通风格的 3D 海洋生存原型。玩家从一艘小木筏出发，收集漂流物，制作工具和生存设施，扩建/强化木筏，下水搜集资源，登陆岛屿砍树，并应对饥渴、缺氧、鲨鱼和野猪。

同时提供离线单人和最多两人共享世界。单人“离线”指加载本地服务提供的游戏后，模拟不依赖外部网络服务；推荐仍用本地 Node HTTP 服务启动，不依赖 file:// 打开。

技术基线：Node.js 18+；`npm start` 执行 server.js；默认监听 0.0.0.0:3000；浏览器访问 http://localhost:3000。无需 npm install。客户端原生 JavaScript + WebGL 1，无第三方运行时依赖、CDN、在线模型或音频下载。资源用本地程序生成。禁止换成俯视 2D、Canvas 假透视或静态场景截图。

源码模块职责：world.js 管岛屿/生态，movement.js 管运动，items.js 管物品事务，targeting.js 管相机/拾取，building.js 管建造，drift.js 管海流，avatar.js 管人物，world-renderer.js 管岛屿/动物，music.js 管音乐，index.html 管 UI/渲染与单人整合，server.js 管 HTTP 和联机权威状态。

WebGL 初始化失败显示具体错误并禁用开始，不冒充正常运行。真正创建着色器、顶点缓冲区、索引缓冲区、深度测试及透视相机。

## 2. 世界尺度、坐标和开局

统一渲染单位为米。逻辑平面坐标用 x、y，换算为 3D 的 X、Z：`X=(x-500)/30，Z=(y-350)/30`；竖直高度 altitude 直接为米，3D 上方向为 +Y。平面 y 减小为北，x 增大为东。不得把逻辑 y 误当竖直高度。

- 初始木筏为 3×3，共9格，格索引 gx、gy 都为 -1、0、1。
- 格中心 `(500+48gx,350+48gy)`；每格 1.6米，初始支撑面积约4.8×4.8米。
- 普通格100耐久、未强化；逻辑甲板站立高度0.52米，筏底上浮阻挡高度-0.72米。
- 新单人/第一个联机玩家在 `(480,350)`，第二个玩家在 `(520,350)`；初始高度0.52，竖直速度0，yaw=0。
- 新玩家生命、饥饿、口渴、氧气全部100，未倒下，选择快捷栏第1格。
- inventory 和 tools 都是空对象，hotbar 是10个空位。不要赠送钩子、食物、淡水或材料。
- 第一位服装颜色 #ffce74，第二位 #83e0d1；名称最大14字符。
- 世界平面边界 x∈[-800,1900]，y∈[-600,1700]，移动到边界钳制。
- 木筏本身固定在世界原点附近，不随海流移动；移动的是自然漂浮物。
- 没有剧情终点、任务树、科技解锁链、航海地图或完整昼夜光照；“第N天”每300秒增加一次，主要是 UI 计时。

## 3. 核心循环与生存数值

所有状态最大100、最小0。满血不因吃饭自动恢复生命。制作与设施动作即时完成，没有当前版本之外的生产队列或等待动画。

## 4. 人物移动状态机

明确实现6个状态：RAFT_GROUNDED、ISLAND_GROUNDED、SURFACE_SWIM、UNDERWATER、FALLING、BOARDING。不要只用“是否在水里”布尔值管理全部情况。

### 4.1 水平控制

WASD相对相机水平朝向移动，斜向归一化，不能斜走更快。设前后输入f=W-S、左右s=D-A、相机水平角θ，则 dx=(s cosθ-f sinθ)/L，dy=(-s sinθ-f cosθ)/L，L为输入向量长度。

| 所在状态 | 逻辑单位/秒 | 米/秒 |
| --- | --- | --- |
| 甲板行走 | 142 | 4.7333 |
| 岛屿行走 | 96 | 3.2 |
| 水面/未达到深潜判定的游泳 | 82 | 2.7333 |
| 深潜 | 56 | 1.8667 |

Shift只对地面移动乘1.55。移动时角色 yaw=atan2(-dx,-dy)，面向移动方向；静止时取相机yaw。因此侧移、后退会让角色朝实际移动方向转，不是始终保持背对镜头。没有跳跃功能；Space专门用于水中上浮。

### 4.2 水中竖直运动

海平面渲染基准0；水面游泳角色基准高度-0.34；一般海底运动下限-7.25。altitude不是头顶高度，角色上下半身通过模型姿态表现。

- 离开地面自由落下，加速度-2.6米/秒²，连续入水。
- 水下按住Space，竖直加速度+2.8米/秒²，上升速度上限1.4米/秒。
- 松开Space，加速度-1.6米/秒²，下沉速度上限1.35米/秒。
- 到水面停止上升，速度归0。持续按Space留在水面；松开后有0.85秒水面宽限，随后继续下沉。
- 从水下升到筏底时被-0.72阻挡，不能穿板上去；允许水平游出木筏下方。
- 深潜视觉/氧气判定：非地面、非攀爬，且高度<-1.05；或在筏下且高度<0。其余接近水面的水中状态用水面游泳表现。
- X/Y分轴移动，阻挡时另一轴仍可滑动。海岸实地和筏侧是阻挡，不能横穿。
- 外层dt上限0.25秒，内部积分子步不大于1/120秒；客户端帧dt自身上限0.05秒。

### 4.3 自动登筏和登陆

不需要按E。角色必须主动在水面向可达外沿移动，不动或背离不被拉上去。高度在-0.34±0.03米。移动方向向目标的归一化点积至少0.3。

木筏候选仅取没有邻格的边：角色离格中心沿法向24～44逻辑单位、沿边切向绝对值≤28；自动触发还要求法向距离≤30，即边外约0.2米内。落点法向位于中心外14单位，切向夹到±18。通过空格洪泛判断该边连通外海；封闭的筏中央洞不算外沿。不存在的地板不支撑角色，接缝不能形成可穿透的细缝。

岛屿按椭圆归一化半径r判定，r在1～1.16可提示，自动触发要求r≤1.04；目标为沿中心方向缩到r=0.94，落点高度取实际地形。

上岸总时长1.2秒。前55%时间先在边外抬升，高点为max(0.65,目标高度+0.12)；后45%用 smoothstep(t)=t²(3-2t)向落点移动并下落贴合。目标地板若途中被破坏，取消攀爬并进入FALLING。不能用瞬移或取消碰撞替代。

## 5. 第三人称镜头与鼠标逻辑

采用右肩偏置第三人称相机，角色通常位于画面中心偏左，中央圆区留给交互。不是第一人称，也不是固定俯视镜头。

- 垂直视场60°；近裁剪0.1米，远裁剪320米。
- 初始水平角0.68弧度、俯仰0.42弧度、距离参数9.2米。
- Mouse Pointer Lock：鼠标横移dx让yaw减去dx×0.0027；竖移dy让pitch加dy×0.0022。
- 普通pitch夹在[-1.05,1.20]弧度。
- 滚轮每档改变距离0.8，范围[5.8,15]。
- 目标点高度：地面altitude+1.05，水面游泳+0.78，潜水+0.24。
- 水平相机半径=d cos(pitch)，竖直偏移=d sin(pitch)；眼位置的竖直基准为角色altitude，目标点再加上述高度。
- 水面有效距离=距离参数×0.82，潜水×0.70，地面×1。
- 潜水且按Space时pitch强制-0.72，从人物下方向上看；潜水未按Space时pitch夹到[-0.82,0.18]。
- 潜水相机眼高度限制[-8.2,-0.28]。
- 用目标-眼位置得到forward，forward叉乘世界up得到right；眼和目标都沿right平移0.85米。
- 相机与拾取投影必须使用同一套计算，否则会出现看见高亮但E拿不到。
- 现版没有完整相机避障系统，不能在文字中宣称摄像机永不穿模。

开始游戏时尝试锁定鼠标。Esc释放鼠标后，能点击制作/设置。再次左键点击画布或“继续控制”只恢复锁定，**该次点击不能再攻击、砍树、放置或拆除**。下一次左键才执行动作。处理浏览器拒绝锁定的错误，显示可再次点击的提示；不得卡死在无法恢复状态。开设置、失焦、锁定变化时清空按键输入，防止自动走动。输入框和键位录入时隔离游戏按键。

## 6. 圆区预选与E拾取

中心小准星加圆形选择区：圆直径14vh，即半径7%视口高度，真正圆形不随宽高比变椭圆。默认细浅蓝边，选中时金色边和光晕；圆下显示物品中文名与“E 拾取”，改键后显示新键。

普通拾取3D距离≤2.8米。距离从玩家平面位置及altitude+1（潜水+0.3）到物品中心计算。物品默认中心高度0.44，固定掉落用其保存高度，海底节点用海床函数+0.4。

候选需在相机前方、投影圆区内、不被地形/甲板挡住。投影按60°FOV；屏幕归一化偏移 sqrt((projectedX×aspect)²+projectedY²)≤0.14。优先圆心偏移最小者；偏移相差<0.001时取深度更近者。不要优先取离人物最近的物品。

潜水时只候选高度<-0.5的普通掉落及海底资源；非潜水只候选高度≥-0.5的普通资源。倒下或攀爬中没有候选。沿眼到物品射线约每0.06米采样检查甲板和岛屿遮挡；当前未对所有树叶/动物/装饰石块做精细遮挡。

高亮采用同一物品模型扩张1.16倍，绘制背面轮廓：正面剔除、暂不写深度、发光金色RGB(1,0.84,0.35)，之后恢复普通绘制。只对所选物品，不能所有近处物体一起发亮。

按E发送明确目标ID与相机参数。服务端重新计算选择，只接受仍为该目标的ID；无目标、过期目标、伪造ID、超距、被队友拾取均失败，不能退化成拾取另一件。成功后从世界原子删除一次并增加物资一次，长按E不因键盘重复连续误捡。

## 14. 界面、按键与交互优先级

以1200×800桌面视口作为参考，画布全屏，深蓝半透明圆角HUD覆盖场景，细边线、浅色文字、金色主按钮。界面不能遮住中心拾取圆区。

- 顶部左：锚图标、漂流纪元/英文副标题、设置、继续控制/视角已锁定。
- 顶部右：离线/连接状态、模型状态、人数、保存、菜单。
- 左侧距边约16px、顶76px，宽220px：生命/饥饿/口渴/氧气条，水深或站立状态，木筏平均耐久；下为两列个人物资，可滚动和点击装备。
- 右侧距边15px、顶76px、宽260px、底72px，可滚动：生存动作、建造拆除模式、配方、群岛指南、最近日志。
- 快捷栏底部居中，10格，每格约42～58宽、54高，底距58px；键号左上、图标居中、数量右下、名在底部。
- 最底部显示WASD、Space、E、T和鼠标说明；中心上方状态提示，Toast约顶部19%，显示约2.2秒。

左键优先级：未锁定→只恢复；已锁定且显式建造模式→执行该模式；否则手持设施→放置；否则手持斧→目标砍树；否则矛→攻击；其他→无有效攻击。E始终是拾取，不承担登筏功能。

## 15. 音乐与音效

三首原创16小节轻音乐按顺序循环，不是单个正弦波一直嗡鸣，也不是下载商业游戏背景曲。音色温和，包含独立旋律、分解和弦、低音和极轻铺底。

| 曲名 | BPM | 主音色 | 半音移调 | 长度 |
| --- | --- | --- | --- | --- |
| 晨光轻舟 | 84 | 三角波拨弦 | 0 | 约46.51秒 |
| 午后海风 | 100 | 正弦波木琴感 | +5 | 39.2秒 |
| 星港晚潮 | 76 | 正弦波柔笛 | -5 | 约51.33秒 |

每小节4拍、8个半拍旋律位置，null代表该位置不触发新音。精确MIDI旋律序列见参数JSON；不能只写“几首轻音乐”让AI任意生成而期待同样旋律。

和弦MIDI循环[48,52,55]、[53,57,60]、[45,48,52]、[43,47,50]；低音根音再降12；分解序列[0,1,2,1,0,2,1,2]，和弦音升12；频率=440×2^((midi-69)/12)。旋律音量系数.082，拨弦伴奏.029（晚潮.020），低音.060/.046，铺底每音.012。主增益=用户音乐音量×.65。

拨弦/木琴起音约.009秒，笛约.060，铺底约.20；有独立衰减/释音，避免突然切断。播放器每100ms调度未来.75秒音符；曲终转下一首，切歌停止旧声部，音量0真正静音。首次用户手势创建/恢复AudioContext，浏览器暂停时可恢复。设置保存在本机。

拾取约720Hz、制作440Hz、丢弃280Hz、普通反馈560Hz，约.08秒短三角波；左键动作附130Hz/.10秒。当前联机结果回调和单人成功动作的音效调用不完全一致，不要求凭空加入环境海浪、脚步、配音体系。

## 16. 保存、联机与数据结构

单人使用localStorage `driftingAge3dSave` 保存世界，正常模拟约每12秒自动保存，物品事务后立即保存，也有手动保存。旧存档继续载入，不清空原物资；新开单人世界把上一份存档复制到 `driftingAge3dSaveBackup`，备份为单份覆盖式，不是版本历史列表。音频键driftingAgeAudio，键位键driftingAgeBindings。

世界至少保存：players、resources、underwaterResources、raft、structures、stations派生计数、islands、trees、animals、worldClock、bounds、shark、事件和生成计时。玩家至少保存坐标/高度/速度/朝向、状态/攀爬、氧气/生命/饥渴、inventory、tools、hotbar、selectedSlot、外观和动画时间。不要只保存背包而丢掉世界掉落/砍树状态。

联机Node为唯一权威，最多2玩家；第3位收到full并关闭连接。客户端发输入不直接指定位置，服务端100ms更新一次并广播快照，移动内部仍按小子步积分。客户端约60ms发一次控制输入，选中格用显式select动作同步，避免旧输入包把制作自动换手改回旧格。

消息类型：welcome、state、result、full；客户端input、action、rename。action包括select/equip/pickup/drop/craft/place/build/armor/repair/demolish/chop/attack/eat/drink/purify/cook/fish/explore/revive/respawn。拾取和建造都提交明确ID并由服务端重验。两人看到相同物资删除、格子删除、设施、树木和动物状态。退出移除玩家并更新人数。

该版没有数据库、账号、联机断线恢复背包或跨服务重启云存档。玩家掉落“永久固定”指当前世界生命周期内不会自然漂走/清理，不能误承诺服务器重启后仍在。单人关闭页面不推进树木计时；联机服务即使没人连接也继续世界模拟。

## 17. 必须执行的验收场景

1. 真正首次空存档进入：9块木筏，10空格，材料/装备全0，角色没有默认钩或氧气瓶。
2. 木筏四侧水面主动游近，无E自动连续登筏；筏底按Space只能到-0.72；游出再上浮可登筏。
3. 松Space连续下沉，按住连续上浮；无一次按键瞬间跳面/穿板。
4. Esc→制作→点画布恢复锁定，该次不误攻击/放置；再次点击才执行；打开关闭设置仍可恢复。
5. 快捷栏10类型全占，手持20木板制作水瓶：20木板完整变成一份掉落，新瓶手持，拾取恢复20。
6. 圆区内木板和更近但圆外塑料：E只取木板；空圆区不取；远处/筏后/被队友拿走的ID失败。
7. 同一种设施放在两个不同指定格，其中一件旋转90°；目标格、朝向与预览一致，重叠放置不扣料。
8. 只强化所瞄准格；重复请求不扣第二次；只维修指定受损格。
9. 指定外侧空格扩建；不能隔空离开现有木筏创建悬空格。
10. 拆设施返原成品，拆地板返半数材料；重复请求无复制；被鲨鱼破坏支撑不吞设施。
11. 自然物持续经过并离开；主动丢物、满栏换手、拆除和砍树物不随海流走；保存重载数量与位置不变。
12. 三岛分别从水面自动登陆，向内走高度贴合地形，走离岛又落水；地下穿岛被阻止。
13. 不同岛动物种类符合表；马/羊/猪与鸟形体可区分，不全是同一种模型换色。
14. 手持斧、对准树、三次有效挥斧倒树；生成木板4、叶2；立即再点不复制；180模拟秒再生。
15. 真实WebGL截图包括人类正背面、绿色设施预览、布局、岛上动物和砍树掉落；GL_NO_ERROR且无页面异常。
16. 三首音乐实际生成不同且非零波形，自动轮换，手动下一首，静音有效，设置重载保留。
17. 两真实客户端同时操作一份资源，只成功一次；拆除/回收双方一致；第3位拒绝，退出后名额恢复。
18. npm start可运行，HTTP返回200；无外部模型失败；浏览器控制台无缺失文件或未定义API。

基准已有28项Node逻辑测试及11类浏览器结果。使用真实Chromium/WebGL/SwiftShader的结果不能等同人工手感、跨公网弱网或硬件GPU性能验收。报告写清楚测试场景使用真实输入还是测试夹具，未运行不能写PASS。

## 18. 明确不属于当前完成范围

完整《木筏求生》物品百科、科技树、冶炼、绳索加工、种植养殖、动物骑乘驯养、船帆移动木筏、容器格子背包、投钩绳索物理、天气和昼夜照明、真实浮力刚体木筏、岛屿无限生成、所有装饰物碰撞、相机全场景避障、工具耐久、专业骨骼动作、多人账号数据库和跨重启存档，均不能被写为本版本既有功能。

复刻优先级：运动与控制、物品不丢失、明确目标事务、实际登陆、同步和保存为P0；模型轮廓/比例/配色、UI布局和音乐风格为P1；不影响核心体验的微小木纹和装饰随机摆动为P2。不能为追求装饰而删掉P0。
