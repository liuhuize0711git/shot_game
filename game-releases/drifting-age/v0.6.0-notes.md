# 0.6.0 — 自选建造、群岛与生态

- 瞄准绿框放置设施，R旋转；指定地板扩建、升级、维修和拆除。设施拆除返还物品，地板返还半数材料。
- 新玩家完全空手；旧存档保留，新开单人世界会备份上一份存档。
- 自然漂浮物随海流经过并离开；丢弃、拆除和砍树掉落固定留存。
- 原创卡通人类模型，空手不显示装备。
- 三座实际可登陆且大小、地形、植被不同的岛，山羊、马、野猪、海鸥、鹦鹉差异分布；斧头砍树三次掉资源，三分钟再生。
- 三首原创轻音乐轮播，提供音量和切歌。

运行：解压后 npm start，浏览器访问 http://localhost:3000，无需 npm install。

验证：28项Node测试、JavaScript语法检查、真实Chromium/WebGL交互与双人WebSocket测试。完整证据和限制见压缩包 QA_REPORT.md。动物尚无骑乘驯养；联机世界仍不跨服务重启保存。

今后游戏设计默认参考《木筏求生》，保持原创源码、模型与音乐。旧版本包保留。
