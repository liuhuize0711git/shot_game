# 漂流纪元 0.5.2

[下载完整游戏包](drifting_age_v0.5.2.zip)

- 水面向木筏外沿游近自动登筏，含接缝/角落；正下方不能穿板。海滩也自动登陆。
- Esc 后可制作或设置；点击游戏画面或“继续控制”恢复视角，恢复点击不误攻击或放置。
- 制作后立即手持成品；十格快捷栏满时丢出原手持整叠，数量保留，可捡回。设施先手持，再站在甲板上左键放置。
- 中央圆区预选：模型亮色轮廓和名称；E 只拾取选中物品，含海底矿石。服务端检查目标、距离和地形遮挡。

验收：16 项 Node 测试通过；真实 WebGL 画面和操作检查、双客户端协议检查通过。协议阶段暂停额外绘制，未做公网弱网、人工手感与物理 GPU 性能验收。详细报告、截图、源码与启动脚本都包含在 ZIP 中。

解压后在项目目录运行 `npm start`，需要 Node.js 18 或更新版本。
